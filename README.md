# 🥁 Drum Kit

An interactive drum kit web app that allows users to play drum sounds using keyboard keys or mouse clicks.

---

## 🎮 Features
- Play sounds using keyboard keys
- Click drum buttons to trigger sounds
- Multiple drum sound effects
- Responsive interaction feedback

---

## 🛠️ Technologies Used
- HTML5 (structure)
- CSS3 (styling & layout)
- JavaScript (event handling & audio control)

---

## 💡 What I Learned
- Event listeners for keyboard and mouse input
- Working with audio in JavaScript (`new Audio()`)
- DOM selection and iteration
- Basic UI interaction design

---

## 📌 Improvements Made
- Added responsive layout for mobile devices
- Improved button interaction feedback
- Organized sound assets into a structured folder
